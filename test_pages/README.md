# Saved web pages

Recipe pages for the import quality test set (`import-quality/`, phase E3). Each is a trimmed copy
made by `npm run import:save-page`: the page's recipe data (JSON-LD or microdata), its address,
name and sharing image, and its recipe card as shown (ingredients, directions, notes). The site's
articles, photos, comments, adverts and scripts are left out. The first line of each file says
where and when it was saved.

This folder is public, like the rest of the test set (decided 2026-10-10).
